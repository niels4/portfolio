ProtectWise

  • The founders hired me as the first UI engineer. I built the UI from the first commit and led it, with the customer-facing API, for 8.5 years.
  • I designed it with Jake Sargeant, the effects artist behind Tron Legacy and Oblivion: desktop-grade, real-time security visuals in a browser, fed by a WebSocket API I built on Kafka streams.
  • TechCrunch named the visualizer one of the company's two distinguishing factors, Forbes credited its “killer UI”, and 451 Research wrote that “the UI on its own could be the wedge to get into opportunities.”
  • Netflix was our first paying customer. Universal Music Group, Motorola Mobility, Surescripts and Pandora followed, and our customer base more than doubled in 2016.
  • We were a Gartner Cool Vendor in 2015, an RSA Conference Innovation Sandbox finalist in 2016, a SINET 16 pick in 2016 and 2017, and an inductee of SC Media's Innovators Hall of Fame in 2019.
  • The team grew from 30 people at our 2015 launch to 95 in 2017, backed by $67M in venture funding, and Verizon acquired us in 2019.

MathViz

Drag a curve yourself in the live Function Viewer.

How it was built, in six steps

  1. 01 Concept An image model drew galleries of concept art; six pictures set the direction.
  2. 02 Fonts Test pages set each candidate font in the app's own strings.
  3. 03 Colors Generated themes, checked for contrast; six kept, three light and three dark.
  4. 04 Prototype A React prototype for behavior that is hard to describe in a spec.
  5. 05 Figma A UX agent designed 13 rounds in Figma, then merged the best ideas into one design.
  6. 06 Development I set the architecture, an AI coding agent matched the styles, and I hunted the jank.

I direct AI tools the way I'd direct a team: I set the direction and the architecture, and I own the result.

Custom Tooling

WebSocket Text Relay

It sends your edits from the editor to the browser as you type, so you see each change without saving the file or reloading the page.

  • I built it to tune the ProtectWise visuals, where even a 5-second rebuild broke the flow of several changes a second.
  • It started as a Vim hack on my machine. I rebuilt it as a language server with Neovim, VS Code and Vite plugins so any web developer can use it.
  • I still use it: math-viz was built on it, and so was the status page above.
